# IP Address Hider

**Prevents accidental public IP leaks during screen sharing and calls.**

## How it Works
This extension automatically scans websites for text matching IPv4 or IPv6 patterns and applies a blur effect.
* **Default:** All IPs are blurred.
* **Reveal:** Simply click the blurred text to view the address.

## Installation

1.  Unzip the downloaded extension file.
2.  Open your browser and navigate to `chrome://extensions` (or select **Manage Extensions** from the menu).
3.  Toggle **Developer mode** on (top right corner).
4.  Click **Load unpacked**.
5.  Select the folder where you extracted the files.
